Quick Start

Get a FHIR MCP server running in under 5 minutes.

# Clone the repo git clone https://github.com/omni-bridge/omni-bridge.git cd omni-bridge # Install dependencies npm install # Configure for your FHIR backend cp .env.example .env # Edit .env with your FHIR_BASE_URL # Start in mock-auth mode (no real OAuth needed) AUTH_PROVIDER=mock npm run dev # Or build and run production npm run build && npm start
